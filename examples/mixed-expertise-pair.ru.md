# Пример: пара с разной экспертизой

Это сокращённый транскрипт режима по репликам. Лена знает рабочую проблему, Макс — ограничения реализации. Они пишут с одного терминала и начинают каждый ответ с имени.

## Начало

```text
Используй $grill-us.

Лена — управляю агентством домашнего ухода. Знаю процесс передачи смены и
отвечаю за определение полезного результата.

Макс — разрабатываю продукт. Знаю ограничения интеграций и приватности,
принимаю решения о технической реализуемости.

Цель — решить, что проверить до разработки продукта для передачи смены.
Стиль — Grill.
Темп — один вопрос за раз.
```

Агент фиксирует участников и задаёт один адресный вопрос.

```text
❓ Q1 → Лена — Подтверждение проблемы: Что вы лично наблюдали при неудачной передаче смены?
```

## Ответы

```text
Лена: В прошлый четверг вечерний сотрудник пропустил заметку о лекарстве.
За шесть недель я видела четыре похожих случая. Один потребовал звонка руководителю.
```

После ответа адресата агент продолжает:

```text
❓ Q2 → Макс — Обратимый тест: Какой минимальный тест не требует хранения данных пациентов?
```

```text
Макс: Мы можем проверить структурированный шаблон на синтетических случаях.
Логин, база и идентификаторы пациентов не нужны.
```

```text
❓ Q3 → всем — Порог успеха: Какой результат оправдает ещё одну неделю работы?
```

```text
Лена: Я хочу, чтобы передача занимала меньше двух минут.

Макс: Согласен с ограничением по времени. В тесте также не должно быть реальных данных пациентов.
```

Агент сохраняет различия между утверждениями:

- количество инцидентов — непосредственное наблюдение Лены;
- предложенный тест — техническая рекомендация и решение Макса о реализуемости;
- две минуты — предпочтение Лены, пока оба участника не приняли его как критерий теста;
- отсутствие реальных данных — техническое решение Макса.

## Разногласие

```text
Лена: Голосовые заметки будут быстрее для сотрудников.
Макс: Голос создаёт риск утечки аудио и ошибок расшифровки. Я за форму.
```

Агент сохраняет обе ветки и направляет следующие вопросы:

```text
❓ Q4 → Лена — Данные о пользователях: Есть ли прямые подтверждения, что набор текста — главная причина сбоев?

❓ Q5 → Макс — Безопасное сравнение: Можно ли сравнить форму и одноразовую запись без сохранения аудио?
```

У Лены нет подтверждений насчёт набора текста. Макс может сделать контролируемый прототип без хранения записи. Пара выбирает эксперимент и не изображает достигнутый консенсус.

## Фрагмент итогового протокола

```text
Результат
Провести пять контролируемых передач на синтетических случаях: три через форму
и две через одноразовую голосовую запись.

Решения и владельцы
- Результат теста: меньше двух минут, заполнены все обязательные поля.
  Владелец: Лена. Макс подтвердил.
- Приватность: без идентификаторов пациентов и сохранённого аудио. Владелец: Макс.

Подтверждение проблемы
- Лена наблюдала четыре пропуска за шесть недель; один потребовал звонка руководителю.

Отложенное разногласие
- Предпочтительный способ ввода в основном продукте. Вернуться после пяти тестов.

Подтверждения
- Лена: подтверждено.
- Макс: подтверждено.
```
