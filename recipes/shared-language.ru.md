# Рецепт: Общий словарь

Используйте этот рецепт, когда участники вкладывают разный смысл в один термин или хотят вести небольшой согласованный словарь проекта. Grill Us управляет разговором нескольких людей, а `domain-modeling` Мэта Покока помогает уточнять термины и оформлять глоссарий.

Минимальная версия Grill Us: `0.6.0`.

## Инструкция для агента

### 1. Установите или проверьте скиллы

Для клиентов Agent Skills установите недостающие зависимости:

```bash
npx skills add monaxovdulov/grill-us --skill grill-us
npx skills add mattpocock/skills --skill domain-modeling
```

Прочитайте оба установленных `SKILL.md`. Проверьте `name: grill-us`, версию Grill Us не ниже `0.6.0` и `name: domain-modeling`. Не загружайте `grilling` Мэта Покока: темп, маршрутизация участников, уровень вмешательства и предложения агента остаются под управлением Grill Us.

### 2. Примените приоритеты

- Grill Us управляет идентичностью участников, авторством, непосредственным опытом, полномочиями, разногласиями и уровнями Record/Grill/Advise.
- `domain-modeling` замечает перегруженные термины, помогает выбрать точный язык проекта и оформляет `CONTEXT.md`, когда пользователь явно выбрал доступный для записи репозиторий.
- Не создавайте ADR, пока пользователь не попросит вести документацию репозитория и решение не пройдёт критерии `domain-modeling`.
- Без выбранного места для записи показывайте изменения словаря в разговоре. Не утверждайте, что они сохранены.

### 3. Согласуйте термин между людьми

У термина может быть одно из состояний:

- `предложен` — определение сформулировано;
- `согласован` — его подтвердили все затронутые участники либо названный ответственный за язык проекта;
- `значение не согласовано` — участники продолжают вкладывать разные смыслы.

Сохраняйте каждое значение вместе с его автором. Перевод, молчание и отсутствие возражений не создают общего определения. В Grill задавайте по одному короткому уточнению. В Record фиксируйте расхождение без собственного термина. В Advise помечайте предложенный агентом термин как «Предложение от агента», пока его не приняли.

### 4. Начните сессию

```text
Используй Grill Us с рецептом «Общий словарь». Grill Us управляет участниками и состоянием решений, domain-modeling — только терминами и форматом глоссария. Не загружай grilling Мэта Покока. Сохраняй разные определения вместе с их авторами. Термин становится согласованным после подтверждения затронутыми участниками или названным ответственным за язык проекта. Записывай файлы только после моего явного выбора репозитория.
```
